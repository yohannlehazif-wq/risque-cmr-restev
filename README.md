# RESTEV 85 WebXR

## Publication
Déposer les fichiers à la racine du dépôt GitHub, puis activer Settings > Pages > main > root.

## Utilisation
- Ordinateur : souris et ZQSD/WASD.
- Casque : navigateur WebXR, bouton ENTRER EN VR, joystick pour se déplacer, gâchette pour sélectionner ou se téléporter au sol.

Une connexion Internet est nécessaire pour A-Frame et les modèles GLB.
